# HabitTrack — User Stories

## User Story 1 — User Registration

As a new user, I want to create an account using my username, email, and password so that I can access the application.

## User Story 2 — User Login

As a registered user, I want to log in using my email and password so that I can access my personal data and habits.

## User Story 3 — Manage Habits

As a user, I want to create, edit, and manage my habits so that I can organize the activities I want to track.

## User Story 4 — Track Habit Progress

As a user, I want to mark a habit as completed so that I can track my daily progress and maintain my streak.

## User Story 5 — View Habit Details

As a user, I want to open a habit's detail screen so that I can view its information and progress history.

## User Story 6 — Save Data

As a user, I want my application data to be stored locally so that my information remains available when I reopen the application.

## User Story 7 — External API

As a user, I want the application to retrieve data from an external API so that I can view useful external information inside the application.

## User Story 8 — Settings and Preferences

As a user, I want to configure application settings and preferences so that I can personalize my experience.

## User Story 9 — Notifications

As a user, I want to configure reminders and receive notifications so that I can remember to complete my habits.
